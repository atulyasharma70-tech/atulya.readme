## 🚀 Featured Projects

### 📄 Resume Shapeshifter — JD-to-Resume Tailoring Engine
*Next.js 16 · TypeScript · Tailwind CSS · Shadcn UI · Groq (Llama 3.3 70B) · Playwright · Zod · Vitest*

An AI-powered web app that analyzes how well a resume matches a target job description and helps tailor it truthfully.

- Multi-dimensional match scoring: Skill Coverage, Responsibility Alignment, Keyword Presence, Seniority Fit
- Prioritized gap analysis (High / Medium / Low) with actionable fixes
- AI bullet rewriting with **hallucination guardrails** that prevent fabricated dates, companies, or metrics, plus confidence labels and risk flags
- PDF export via headless Chromium, and PDF/DOCX parsing with `pdf-parse` and `mammoth`

🔗 **[Live Demo](https://resume-shapeshifter-zeta.vercel.app)**

### ✉️ The Closer — Cold Email Writer & Automated Sending Platform
*Python · Flask · SMTP/IMAP (Gmail) · CSV Logging · Pytest*

An outreach tool for job seekers with both a Flask web dashboard and a terminal CLI.

- Safe-by-default **Dry Run** mode that generates `.eml` previews without connecting to SMTP
- Gmail SMTP/IMAP integration to send emails and auto-save drafts
- Status tracking (Sent, Drafted, Skipped, Failed) logged to structured CSV
- Modular architecture (config, models, generator, sender, logger) with unit and integration tests using mocked SMTP/API layers
